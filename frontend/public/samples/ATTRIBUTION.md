# Instrument samples

The audio files in `fluidr3/` are selected General MIDI samples from
[FluidR3 GM](https://github.com/gleitz/midi-js-soundfonts/tree/gh-pages/FluidR3_GM),
rendered and hosted by Benjamin Gleitzman. The original SoundFont is released
under the [Creative Commons Attribution 3.0 license](https://creativecommons.org/licenses/by/3.0/).

IFLY bundles a small subset for offline playback. The sample file names and
instrument names are preserved. Run `scripts/fetch-instruments.ps1` to retrieve
the same selection from the source repository.
